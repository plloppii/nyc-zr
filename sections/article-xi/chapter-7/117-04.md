# 117-04 Subdistricts

In order to carry out the purposes and provisions of this Chapter, six subdistricts are established within the **_Special Long Island City Mixed Use District_**, as follows:

Court Square Subdistrict, as set forth in Section [117-40](https://zr.planning.nyc.gov/article-xi/chapter-7/117-40), inclusive;

Dutch Kills Subdistrict, as set forth in Section [117-60](https://zr.planning.nyc.gov/article-xi/chapter-7/117-60), inclusive;

Hunters Point Subdistrict, as set forth in Section [117-10](https://zr.planning.nyc.gov/article-xi/chapter-7/117-10), inclusive;

Northern Hunters Point Waterfront Subdistrict, as set forth in Section [117-30](https://zr.planning.nyc.gov/article-xi/chapter-7/117-30), inclusive;

Queens Plaza Subdistrict, as set forth in Section [117-50](https://zr.planning.nyc.gov/article-xi/chapter-7/117-50), inclusive; and

Queens Plaza West Subdistrict, as set forth in Section [117-20](https://zr.planning.nyc.gov/article-xi/chapter-7/117-20), inclusive.

In each of these subdistricts, certain special regulations apply which do not apply within the remainder of the **_Special Long Island City Mixed Use District_**. The subdistricts are outlined on Map 1 in Appendix A of this Chapter.
