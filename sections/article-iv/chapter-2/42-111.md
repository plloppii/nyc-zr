# 42-111 Use Group I – general use allowances

The following table includes **_uses_** classified as Use Group I and sets forth their allowances by **_Manufacturing District_**. Notations found in the table are further described in Section [42-10](https://zr.planning.nyc.gov/article-iv/chapter-2/42-10) (USE ALLOWANCES). Where permitted as-of-right in a **_Manufacturing District_**, all **_uses_** listed as “Open Uses” in the table shall be unenclosed, except for ancillary **_buildings or other structures_**.

| --- | --- | --- | --- | --- |
| **● = Permitted** ♦ **= Permitted with limitations ○ = Special permit required** **– = Not permitted S = Size restriction P = Additional conditions U = Open use allowances** |  |  |  |  |
| **Uses** | **M1** | **M2** | **M3** | **PRC** |
| **Agriculture** |  |  |  |  |
| Agricultural **_uses_**, including greenhouses, nurseries, or truck gardens | ● ~P U | ● ~P U | ● ~P U | G |
| **Open Uses** |  |  |  |  |
| Cemeteries | ● | – | – | N/A |
| Golf courses | ● | – | – | \* |
| Outdoor racket courts | ● ~P | – | – | G |
| Outdoor skating rinks | ● | ● | ● | G |
| **_Public parks_** or playgrounds or private parks | ● | – | – | N/A |
| Sand, gravel, or clay pits | ○ | ○ | ○ | N/A |
