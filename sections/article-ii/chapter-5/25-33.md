# 25-33 Waiver of Requirements for Spaces Below Minimum Number

R1 R2 R3 R4 R5 R6 R7 R8 R9 R10 R11 R12

In all districts, as indicated, except for the **_uses_** listed in Section [25-331](https://zr.planning.nyc.gov/article-ii/chapter-5/25-331) (Exceptions to application of waiver provisions), the parking requirements set forth in Sections [25-31](https://zr.planning.nyc.gov/article-ii/chapter-5/25-31) (General Provisions) or [25-32](https://zr.planning.nyc.gov/article-ii/chapter-5/25-32) (Special Provisions for a Single Zoning Lot With Uses Subject to Different Parking Requirements) shall not apply to permitted non-**_residential uses_** if the total number of **_accessory_** off-street parking spaces required for all such **_uses_** on the **_zoning lot_** is less than the number of spaces set forth in the following table:

| Districts | Number of Spaces |
| --- | --- |
| R1 R2 R3 R4 R5 | 10 |
| R6 R7-1 R7B | 25 |
| R7-2 R7-3 R7A R7D R7X R8 R9 R10 R11 R12 | 40 |
