# 42-191 Use Group IX – general use allowances

The following table includes **_uses_** classified as Use Group IX and sets forth their allowances by **_Manufacturing District_**. Such **_uses_** are categorized as general storage, specialized storage, or vehicle storage, as provided in paragraphs A, B and C of this Section. Notations found in the table are further described in Section [42-10](https://zr.planning.nyc.gov/article-iv/chapter-2/42-10) (USE ALLOWANCES).

| **USE GROUP IX(A) – GENERAL STORAGE** |  |  |  |  |
| --- | --- | --- | --- | --- |
| **● = Permitted** ♦ **= Permitted with limitations ○ = Special permit required** **– = Not permitted S = Size restriction P = Additional conditions U = Open use allowances** |  |  |  |  |
| **Uses** | **M1** | **M2** | **M3** | **PRC** |
| **General Storage** |  |  |  |  |
| Building materials or contractors' yard | ● ~P U | ● ~P U | ● ~P U | D2 |
| Depositories for storage of office records, microfilm or computer tapes, or for data processing | ● | ● | ● | D2 |
| Micro-distribution facilities | – | – | – | D2 |
| Moving or storage offices | ● ~P | ● ~P | ● ~P | D2 |
| **_Self-service storage facility_** | ♦ ~P | ♦ ~P | ♦ ~P | D2 |
| Trucking terminals or motor freight stations | ● ~P U | ● ~P U | ● ~P U | D2 |
| Warehouses | ● ~P | ● ~P | ● ~P | D2 |
