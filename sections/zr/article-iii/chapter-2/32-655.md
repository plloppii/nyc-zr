# 32-655 Height of signs in all other Commercial Districts

C1 C2 C3 C4 C5 C6 C7

In the districts indicated, no permitted **_sign_** shall extend above **_curb level_** at a height greater than the following:

| Districts |  | Maximum Height (in feet) |
| --- | --- | --- |
| C1 C2 C3 C5-1 C5-2 C5-3 C5-5 |  | 25 |
| C4 C5-4 C6-1 C6-2 C6-3 C6-4 C6-6 C6-8 C6-9 C6-11 C6-12 C7 |  | 40 |
| C6-5 C6-7 |  | No restriction as to height |
